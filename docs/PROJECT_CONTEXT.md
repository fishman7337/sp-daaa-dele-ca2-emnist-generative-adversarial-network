## Repository Purpose

The repository preserves the original coursework notebook and adds production-style project hygiene around it:

- Clear documentation.
- A standard folder structure.
- Reusable Python utilities.
- Tests and CI.
- Security scanning.
- Environment and artifact management.

## Naming

The project is presented as **EMNIST Generative Modeling Lab** because the notebook goes beyond a single GAN. It includes EMNIST preprocessing, VAE/CVAE work, multiple GAN families, and comparative evaluation.
