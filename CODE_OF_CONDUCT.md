# Code Of Conduct

## Our Standard

This project should remain a respectful learning and collaboration space. Contributors are expected to:

- Communicate with care, patience, and professionalism.
- Welcome constructive feedback on code, documentation, experiments, and methodology.
- Credit academic sources, external references, datasets, and prior work.
- Avoid harassment, discriminatory language, personal attacks, or intentionally disruptive behavior.
- Respect Singapore Polytechnic coursework integrity requirements and any dataset usage terms.

## Scope

This code of conduct applies to project issues, pull requests, discussions, documentation, notebooks, and any related collaboration channels.

## Reporting

Report unacceptable behavior to the repository maintainer. Reports should include the relevant links, screenshots, or context needed for fair review.

## Enforcement

Maintainers may remove content, request changes, restrict participation, or block contributors whose behavior harms the project or its contributors.
